## Description

The Smart Study Planner is a console-based Python program designed to help a student record, review and analyse study sessions across different subjects during a semester.

The program stores study sessions and allows the user to view and analyse their study activities.

## Main Features

* Add a study session
* View all recorded study sessions
* Search study sessions by subject
* Classify study sessions as Short, Medium or Long
* View overall study statistics
* View total study time per subject
* Identify the subject with the least study time
* Identify the longest study session
* Save study sessions to `study_log.txt`
* Load previously saved study sessions when the program starts
* Handle invalid user input

## Session Classification

| Duration         | Classification |
| ---------------- | -------------- |
| Under 30 minutes | Short          |
| 30–90 minutes    | Medium         |
| Over 90 minutes  | Long           |
